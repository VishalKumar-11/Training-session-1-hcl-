About DocLocker

One organized home for academic, identity, and personal records

Inspired by modern citizen document lockers, DocLocker brings clarity to everyday paperwork—letting you upload PDFs or scanned images, organize them into categories, and simulate snapshot backups in seconds.

  • Categorized folders for Aadhaar, PAN, Marksheets, Certificates, and general records.
  • Built-in client-side validation for file type, size limits, and password complexity.
  • Pure HTML5, CSS3, and Vanilla JavaScript architecture with zero framework bloat.
Prototype Notice: This is a student frontend prototype. Authentication, lockout counters, document storage, and backup snapshots run locally in your browser. Never upload real government IDs or reuse real passwords.
Platform Capabilities

Everything needed to manage a clean digital vault

Designed around fast uploads, clear file previews, instant search, and dependable recovery workflows.

01. Upload & Validation

Drag-and-Drop Document Intake

Drop PDF, JPG, JPEG, or PNG files directly into the upload zone or pick from your device. DocLocker validates formats and enforces the 10 MB size ceiling before showing live upload progress.

02. Search & Categories

Instant Search & Category Filtering

Locate any record by filename or filter across Aadhaar, PAN, Marksheets, and Certificates. Preview uploaded files, trigger instant downloads, or remove outdated copies safely.

03. Backup & Restore

Snapshot Backup Simulation

Create local backup snapshots, export a downloadable vault copy, and restore deleted sample or uploaded documents in one click—while clearly distinguishing prototype simulation from real cloud storage.

04. Login Security Demo

Attempt Counter & Lockout State

Tracks consecutive invalid login attempts and demonstrates a temporary account lockout after 3 failed tries, paired with transparent guidance on server-side security enforcement.

Frequently Asked Questions

Common questions about DocLocker

Details on supported file types, prototype behavior, and account security demonstrations.

DocLocker supports PDF, JPG, JPEG, and PNG files up to a maximum file size of 10 MB per document. Unsupported extensions or oversized files are blocked immediately with a clear error message.
As a frontend-only student prototype, DocLocker uses browser storage (localStorage and sessionStorage) to simulate registration, document metadata, and backup snapshots. Real cloud storage and encryption require a dedicated backend server and private object storage.
Entering invalid credentials increments a consecutive failure counter. After 3 failed attempts, the login form enters a temporary 30-second lockout state to demonstrate brute-force protection UX. Because client-side JavaScript cannot permanently enforce security, real lockout rules must live on a backend API.
